🚀 Relying Party (RP) SSO Onboarding Guide

Step-by-Step Developer Guide for Single Sign-On Integration via WSO2 IS 7.0 Identity Broker

← Part 1: WSO2 Hosted Flow ⚡ Part 2: eID Federated Flow 🏆 Part 3: Master Deck 🔀 Multi-RP Widget Deck
⚡ Rule 1: Zero Backend Code Changes
No code changes in backend Program.cs are ever needed. RP applications onboard 100% dynamically at runtime via database entries or WSO2 REST APIs without app restarts.
🌐 Rule 2: Connect via WSO2 IS Broker
Every Relying Party (COCI, Tax, Health, Fintech) connects directly to WSO2 IS 7.0 (Identity Broker), NOT directly to eID. WSO2 handles OAuth2 client IDs, redirect URIs, and OIDC token issuing.
🔒 Rule 3: Pairwise Privacy (PPID)
Internal citizen UIN is strictly hidden. WSO2 issues a Pairwise Pseudonymous Identifier (PPID) unique to each RP app to prevent cross-app citizen tracking.

Step 4 Implement OIDC Auth Controller Code
Code Implementation

Implement authentication routes: /auth/wso2/redirect (redirects to WSO2 authorize URL), /auth/wso2/callback (exchanges authorization code via HTTP Basic Auth), and /auth/wso2/logout.

app/Http/Controllers/Auth/Wso2Controller.php 
<?php

namespace App\Http\Controllers\Auth;

use App\Http\Controllers\Controller;
use App\Models\User;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;
use Illuminate\Support\Facades\Http;
use Illuminate\Support\Str;

class Wso2Controller extends Controller
{
    public function redirect(): RedirectResponse
    {
        $state = Str::random(40);
        session(['oauth_state' => $state]);

        $query = http_build_query([
            'client_id' => config('wso2.client_id'),
            'redirect_uri' => config('wso2.redirect_uri'),
            'response_type' => 'code',
            'scope' => 'openid profile email',
            'state' => $state,
        ]);

        return redirect(config('wso2.base_url') . '/oauth2/authorize?' . $query);
    }

    public function callback(Request $request): RedirectResponse
    {
        $state = session()->pull('oauth_state');
        if (!$state || $state !== $request->state) {
            return redirect('/')->withErrors(['oauth' => 'Invalid state.']);
        }

        // Exchange Authorization Code for Tokens
        $response = Http::withBasicAuth(config('wso2.client_id'), config('wso2.client_secret'))
            ->asForm()->withoutVerifying()
            ->post(config('wso2.base_url') . '/oauth2/token', [
                'grant_type' => 'authorization_code',
                'redirect_uri' => config('wso2.redirect_uri'),
                'code' => $request->code,
            ]);

        $tokenData = $response->json();
        $accessToken = $tokenData['access_token'];

        // Fetch UserInfo from WSO2
        $userResponse = Http::withoutVerifying()->withToken($accessToken)
            ->get(config('wso2.base_url') . '/oauth2/userinfo');
        $wso2User = $userResponse->json() ?? [];

        // Enrich Profile from eID Core API
        $eidRes = Http::withoutVerifying()->get(config('eid.base_url') . '/api/v1/auth/userinfo-public?email=' . urlencode($wso2User['email'] ?? ''));
        if ($eidRes->successful()) {
            $wso2User = array_merge($wso2User, $eidRes->json());
        }

        session(['user_profile' => $wso2User]);

        // Link User locally & Login
        $user = User::firstOrCreate(
            ['email' => $wso2User['email'] ?? $wso2User['sub']],
            ['keycloak_id' => $wso2User['sub'], 'name' => $wso2User['name'] ?? 'eID Citizen']
        );

        Auth::login($user);
        return redirect()->intended('dashboard');
    }
}

Step 6 Common Troubleshooting & Fixes
Troubleshooting Matrix

Quick reference matrix for resolving common integration errors during WSO2 IS 7.0 onboarding.

WSO2 Error Message Root Cause Immediate Resolution
Cannot find an application associated with consumer key The WSO2_CLIENT_ID sent in the request does not exist in WSO2's Service Provider store. Use registered key eiMgOByxPuwybGw2CKYW9nJl8_oa or register the app via WSO2 REST API.
Registered callback does not match with the provided url The redirect_uri parameter sent by the RP does not match the registered callback pattern. Update WSO2 callback URL regex to include your RP port: regexp=http://(coci\.test|127\.0\.0\.1:8000|localhost:8000)/auth/wso2/callback
Invalid PKCE Code Verifier PKCE transformation method mismatch or incorrect SHA-256 base64url encoding. Use code_challenge_method=S256 and base64url encode hash('sha256', $verifier, true) without padding.
