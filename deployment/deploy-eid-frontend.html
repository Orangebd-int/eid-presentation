1. Overview

The eID Frontend is the public web portal for citizens, PSC operators, and system administrators. It is a Next.js application that calls the eID API for all backend operations and handles OIDC login redirects.

ItemValue
FrameworkNext.js 16 (React 19)
Default port3000
Build commandnpm run build
Start commandnpm run start
Env varsNEXT_PUBLIC_API_URL, NEXT_PUBLIC_OIDC_URL
NEXT_PUBLIC_* variables are embedded at build time. You must rebuild after changing them. Set them before running npm run build.

3. Install Node.js 20 on Ubuntu

# Update system
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl git unzip

# Install Node.js 20 LTS via NodeSource
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# Verify
node --version    # should show v20.x
npm --version
Alternatively install via nvm if you need multiple Node versions on the same server. For production, the system-wide NodeSource install is simpler.

4. Upload project to server

Option A — Git clone

sudo mkdir -p /opt/eid-platform
sudo chown $USER:$USER /opt/eid-platform
cd /opt/eid-platform

git clone <your-git-repo-url>/eid-frontend.git
cd eid-frontend

Option B — SCP / rsync

# SCP
scp -r /path/to/eid-frontend user@your-server-ip:/opt/eid-platform/

# rsync (excludes node_modules and .next)
rsync -avz --exclude 'node_modules' --exclude '.next' --exclude '.git' \
  /path/to/eid-frontend/ \
  user@your-server-ip:/opt/eid-platform/eid-frontend/
Do not upload node_modules or .next from your local machine. Always run npm ci and npm run build on the server.

5. Environment variables

Create the production environment file before building.

cd /opt/eid-platform/eid-frontend
nano .env.production

5.1 Production values

# .env.production
NEXT_PUBLIC_API_URL=https://eid-api.gov.sx/api
NEXT_PUBLIC_OIDC_URL=https://eid-api.gov.sx

5.2 Development / staging values (reference)

# .env.local (development only)
NEXT_PUBLIC_API_URL=http://localhost:5026/api
NEXT_PUBLIC_OIDC_URL=http://localhost:5026
URL rules:
  • NEXT_PUBLIC_API_URL must end with /api
  • NEXT_PUBLIC_OIDC_URL must NOT have a trailing slash
  • Both must use HTTPS in production
  • Must match Oidc__LoginUrl base in the eID API config (https://eid.gov.sx/login)

5.3 Also create systemd env file

sudo mkdir -p /etc/eid-frontend
sudo cp .env.production /etc/eid-frontend/env
sudo chmod 600 /etc/eid-frontend/env

6. Install dependencies & build

cd /opt/eid-platform/eid-frontend

# Load production env for build
export $(grep -v '^#' .env.production | xargs)

# Clean install from lockfile
npm ci

# Production build (embeds NEXT_PUBLIC_* vars)
npm run build

# Verify build output
ls -la .next/

6.1 Test run (manual, before systemd)

cd /opt/eid-platform/eid-frontend
export $(grep -v '^#' .env.production | xargs)
PORT=3000 npm run start

In another terminal:

curl -s -o /dev/null -w "HTTP %{http_code}\n" http://127.0.0.1:3000/login

Press Ctrl+C to stop once verified.

6.2 Set file ownership

sudo chown -R www-data:www-data /opt/eid-platform/eid-frontend

7. systemd service

sudo nano /etc/systemd/system/eid-frontend.service
[Unit]
Description=Sint Maarten eID Frontend (Next.js)
After=network.target eid-api.service
Wants=eid-api.service

[Service]
Type=simple
User=www-data
Group=www-data
WorkingDirectory=/opt/eid-platform/eid-frontend
Environment=NODE_ENV=production
Environment=PORT=3000
EnvironmentFile=/etc/eid-frontend/env
ExecStart=/usr/bin/npm run start
Restart=always
RestartSec=10

# Security
NoNewPrivileges=true
ProtectSystem=strict
ProtectHome=true
ReadWritePaths=/opt/eid-platform/eid-frontend

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload
sudo systemctl enable eid-frontend
sudo systemctl start eid-frontend
sudo systemctl status eid-frontend

# Live logs
sudo journalctl -u eid-frontend -f

8. nginx reverse proxy

sudo apt install -y nginx
sudo nano /etc/nginx/sites-available/eid-frontend
server {
    listen 80;
    server_name eid.gov.sx;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name eid.gov.sx;

    ssl_certificate     /etc/ssl/certs/eid.gov.sx.crt;
    ssl_certificate_key /etc/ssl/private/eid.gov.sx.key;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        proxy_read_timeout 60s;
    }

    # Next.js static assets (optional cache headers)
    location /_next/static/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_cache_valid 200 365d;
        add_header Cache-Control "public, max-age=31536000, immutable";
    }
}
sudo ln -s /etc/nginx/sites-available/eid-frontend /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
Free TLS with Let's Encrypt: sudo apt install certbot python3-certbot-nginx && sudo certbot --nginx -d eid.gov.sx

9. Firewall

sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
sudo ufw enable
sudo ufw status

Port 3000 stays internal. Public access is through nginx on port 443 only.

10. Verify deployment

# Service status
sudo systemctl is-active eid-frontend

# Local check
curl -s -o /dev/null -w "HTTP %{http_code}\n" http://127.0.0.1:3000/login

# Public HTTPS check
curl -s -o /dev/null -w "HTTP %{http_code}\n" https://eid.gov.sx/login

# Confirm API connectivity from browser DevTools Network tab:
# requests should go to https://eid-api.gov.sx/api/...

Align with eID API config

Ensure the eID API has this setting (in /etc/eid-api/env):

Oidc__LoginUrl=https://eid.gov.sx/login

Restart the API after changing:

sudo systemctl restart eid-api

13. Troubleshooting

ProblemSolution
Build failsCheck Node version (node -v must be 20+). Delete node_modules and .next, run npm ci again
API calls go to localhostNEXT_PUBLIC_* not set at build time — rebuild with correct .env.production
502 Bad GatewayFrontend not running — sudo systemctl status eid-frontend
CORS errors in browserAdd https://eid.gov.sx to API CORS in Program.cs, rebuild API
OIDC redirect failsVerify Oidc__LoginUrl in API matches frontend URL exactly
Permission deniedsudo chown -R www-data:www-data /opt/eid-platform/eid-frontend
Port 3000 in usesudo lsof -i :3000 — stop conflicting process
Static assets 404Rebuild: npm run build and restart service
